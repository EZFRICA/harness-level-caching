**Reading.**

- With H3 on, the tool cache served 1 web search out of 15 to 18 in each run, although the scenario asks three questions twice word for word: the model rephrases its query each time, so an exact key rarely repeats.
- The tape replayed 2 to 5 queries per run across runs, for the same reason; most searches were live calls.
- The rec run recorded the tape; it is an H3 on run whose searches were all live.

**Limits.**

- One synthetic French scenario of 16 turns, two runs per arm, one model; live Tavily answers, recorded on a tape shared by the runs.
- Tool time per call is real (about 1.7 to 2.2 s live) or replayed with its recorded latency.
- Tavily calls are not in the cost column: 65 live calls in these runs, inside the free monthly credits (1 credit per basic search, 0.008 USD per credit beyond them).
- Answer quality is not measured.

# A semantic key for the web search (hypothesis, threshold 0.90)

Generated by `harness-cache figures` from `docs/measured/runs/`. Do not edit.

**Question.** If a web query close enough to one already answered in the session gets that answer (cosine of local embeddings at least 0.90), how many more searches are served, and are the matches right?

| run | turn ms, median [95% CI] | model calls | tool cache hits / calls | cost USD |
|---|---|---|---|---|
| `nebius-dsv4flash-onnx-web-sem090-v1` | 7001 [2883, 8537] | 29 | 1/21 | 0.0088 |
| `nebius-dsv4flash-onnx-web-sem090-v2` | 7994 [3912, 9899] | 30 | 1/21 | 0.0089 |
| `nebius-dsv4flash-onnx-web-h3on-v1` | 6076 [3028, 8999] | 32 | 1/22 | 0.0113 |
| `nebius-dsv4flash-onnx-web-h3on-v2` | 6852 [2801, 7843] | 30 | 1/20 | 0.0125 |

Latency statistics skip the first turn of each run. Reproduce: `as web-h3-exact-key, with -e HC_WEB_SEMANTIC_TAU=0.90`

**Reading.**

- The semantic key served 2 more web searches per run (3 of 18 counting the exact hit, against 1 of 15 to 18 with exact keys); the tool cache column counts exact hits only.
- Of the 4 semantic matches, one is wrong: a query about 2024 got the answer recorded for 2025. One more matched a query that also asked for the venue to one that did not.
- The local embedding model scores queries that differ only by a year at 0.95 and above (measured on the 65 recorded queries), so no threshold separates them.

**Limits.**

- Two runs, one scenario, one model; the threshold was chosen on the same tape it was used on (in sample).
- Matches were judged by reading the 4 pairs, not by a rule.
