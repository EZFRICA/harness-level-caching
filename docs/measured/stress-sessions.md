**Reading.**

- naive's last request is about 5500 tokens and grows with every turn; cama's stays near 1600 and topk's near 700: the memory is bounded by construction.
- On the hot path alone, naive costs more than cama from turn 4 in S1 and from turn 38 in S2, where every turn is a page fault.
- The v1 runs created a provider cache after every turn because the echo extractor rewrites memory every turn; the stable admission (decision 0010) removes that waste.

**Limits.**

- Echo model: answers carry no meaning, the extractor writes every turn, and costs are projections at gemini-3.5-flash-lite prices, not money spent.
- Generated English scenarios with fixed seed 20261023; one run per arm.
- The same profile on the real model is measured separately (S1 on Gemini).
