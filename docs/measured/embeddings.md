Latency statistics skip the first turn of each run. Reproduce: `CAMA_LLM=gemini CAMA_EMBEDDER=<gemini|onnx> docker compose up -d && docker compose exec cama cama run /scenarios/assistant_fr_v1.jsonl --fresh --mode <cama|topk>`

**Reading.**

- The memory column (turn minus model call) falls by an order of magnitude when the query embedding is local; the remote embedding round trip was the memory cost.
- The local model loads into the process: peak RSS grows by several hundred MB, which matters on a constrained device.

**Limits.**

- One run per row, 23 turns, one synthetic French scenario; the warm-up turn is excluded from latency.
- Routing thresholds differ per embedding space and are not calibrated on a holdout; tier counts are not comparable across rows.
- Answer quality is not measured.
