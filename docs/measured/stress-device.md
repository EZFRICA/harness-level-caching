Latency statistics skip the first turn of each run. Reproduce: `docker run --rm --cpus 0.5 --memory <limit> --memory-swap <limit> ... harness-cache:dev harness-cache run /scenarios/agentic_fr_v1.jsonl --fresh (see docs/journal for the full command)`

**Reading.**

- With the ONNX model the process holds about 660 MB; at a 512 MB limit it was killed while loading the model (exit code 137, runs/echo-onnx-s4-cpu05-512m-v1.exit.json).
- On half a CPU the harness itself costs about 15 ms per turn with ONNX: small next to a model call of about a second.
- Without a neural embedder the harness runs in about 40 MB, but routing then has no semantic quality: that line shows the floor of the harness, not a usable configuration.

**Limits.**

- Echo model with no latency: the turn column is the harness alone.
- One run per limit; a phone's memory and CPU are not those of a container: to be checked on the Pixel 4 XL.
- A smaller embedding model (EmbeddingGemma 2 ONNX, MiniLM L6) is the next measure for 2 GB devices.
